# 507 Mechanical Movements — interactive edition

All 507 movements from Henry T. Brown's *Five Hundred and Seven Mechanical Movements* (1868), with plain-English descriptions, notes on where each is used today, and interactive simulations for 505 of them. Plates 262 and 263 have no simulation because their descriptions could not be recovered. Simulations marked "schematic" show how the movement works rather than reproducing Brown's exact drawing.

Static site, no build step. To publish with GitHub Pages:

1. Put these files at the root of a repository (index.html, js/, README.md).
2. In the repository: Settings → Pages → Build and deployment → Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
3. The site appears at `https://<your-username>.github.io/<repo-name>/`.

Links to a single movement use `#m<number>`, e.g. `.../#m211`.

Text is summarised from the 1868 edition (public domain). Drawings and simulations are new interpretations.
